# AI 985/211 判定规则文档

简历提取模型会收到一份中文规则文档，其中包含教育部历史 985/211 名单的 112 个
版本化实体、受控别名、严格匹配规则和排除项。运行时名单不是手工复制的，而是由
[`app/resources/985_211_institutions.json`](../app/resources/985_211_institutions.json)
生成并注入 [`app/resources/ai_985_211_rulebook.md`](../app/resources/ai_985_211_rulebook.md)
的 `{{ROSTER_ENTRIES}}` 位置，避免文档与本地校验表漂移。

AI 对每条教育经历返回：

- `ai_985_211_judgment`：`true` 或 `false`；
- `ai_institution_roster_id`：仅正向判断时返回的历史名单 ID。

服务端会再次用同一份本地名单验证 ID。通过验证的正向结果标记为 `ai_rulebook`；
学校原文及全部保留字段通过证据校验后，AI 结果自动进入筛选库。未命中、负向、名称
模糊或无法判断的情况统一写为 `false`，符合当前产品的二值规则。

判定边界：只使用历史 985/211 名单；不得用“双一流”、排名、部属身份或名称包含关系
推断。独立学院、继续教育、分校/校区、合作办学等名称必须严格处理。985 是 211 的
子集，因此任一有效学历教育经历命中 112 所历史白名单即可得到正向结论。

权威来源：教育部 [“985工程”学校名单](https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html)（39 所）和 [“211工程”学校名单](https://www.moe.gov.cn/srcsite/A22/s7065/200512/t20051223_82762.html)（112 所）。
