# 历史 985/211 院校判定规则（供简历提取模型使用）

规则版本：`{{REGISTRY_VERSION}}`

## 任务范围

你只根据简历中已经抽取、且有页码证据的“学历教育院校”做判断。候选人级字段
`is_985_211` 的语义是：任意一条有效学历教育经历命中历史 985 或 211 名单，即为
`true`；其余所有情况均为 `false`。985 是 211 的子集。

对每一条 education 输出：

- `ai_985_211_judgment`：`true` 或 `false`；
- `ai_institution_roster_id`：仅在 `true` 时填下方名单中完全一致的一条 roster ID；
  `false` 必须为 `null`。

## 严格判定方法

1. 只在院校名称经全半角、大小写、空白和中文括号规范化后，精确命中下方“名单实体”
   或其“受控别名”时，输出 `true` 与对应 roster ID。
2. 学校名称明确、是正常学历教育院校、但不在名单或受控别名中时，输出 `false`。
3. 没有院校名称、名称不完整、来源文字相互冲突，或无法确认它是否为独立的学历教育
   院校时，一律输出 `false`，不要猜测 roster ID。
4. 保持 `school_name_raw` 原文，不要为了命中名单把它改写成标准校名；roster ID 只是
   额外的规则匹配结果。

## 禁止推断与排除项

- “双一流”、部属、排名、学科评估、985 工程优势学科创新平台都不能替代历史
  985/211 名单。
- 禁止子串、拼音近似、常识联想或按学校声誉模糊匹配。
- 独立学院、附属中学、继续教育学院、海外学院、合作办学、研究生院、分校和校区，
  不能仅因名称包含名校而命中；不能确认时输出 `false`。
- 北京协和医学院单独出现时不能自动等同清华大学；只有学历/学位授予单位明确为
  清华大学时才可按清华大学判断。
- 短训、访学、交换、辅修、课程、证书项目不是有效学历教育经历，不得单独触发
  候选人级 `true`。
